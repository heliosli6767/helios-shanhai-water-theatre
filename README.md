# 山海水戏（页面原型）

数字资产工作文件统一归档到 [资料库](资料库/README.md)，按首页／故事、背景／人物／道具／特效、单个资产逐级分类。完整状态见 [资产清单](资料库/资产清单.md)。原有网页素材路径保持有效。

一个无需安装构建依赖的网页原型。请通过本地 HTTP 服务打开（手势模型不支持直接通过 `file://` 运行）。在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

当前流程：入口群像 → “九岛水道”大世界中的九本悬浮古书 → 整页故事背景上的悬浮白话卷页或横排拼音竹卷 → 水上戏台。故事页人物和道具位于右侧，切换原文时景物保持原位。水上戏台可在底部切换五种水幕，选择会在本机保存。

九个故事、27 幕已接入全部 119 个故事资产；首页使用群像与三种特效资产。125 项清单中的其余两项是风格参考、旧版水墨背景，不强行放入剧情。原始图片及 Blender 工程不变。当前运行的是图片分层、倒影、水纹和前端动作的 **2.5D 水戏**，不是真正的骨骼 3D 人物动画，也未在网页中加载 `.blend` 文件。

水上戏台有三种模式：手势模式（默认）、按钮模式、演绎动画。角色由剧情自动分配，不再强制选择左右手。多数故事使用任意一只手；夸父与太阳、黄帝之战中的对应段落使用双手。精卫严格按女娃入海 → 消隐化鸟 → 精卫衔木填海交接，不会同时出现女娃与精卫。每个动作完成后自动推进，已移除幕次按钮。按钮模式用 WASD / 方向键走位，空格演出当前动作。点击右上角“演绎动画”即启幕连续播放，左下角仅保留暂停/继续，无第二次开始确认。正文、拼音与原典核查说明保留。

全部 55 个动作都有独立的“怎么做 + 你会看到什么”提示。手势的上/中/下明确指左上角摄像头预览框，不是水上舞台。每个手势节点先留 1.8 秒阅读，再接受约 0.7 秒稳定姿态；进度条给出确认进度。张掌无需先握拳：已张开的手放在预览中央保持即可。抬/降手需从预览中部开始；投掷/射箭需先捏住片刻再松指。动作结束后保留结果 1.4 秒再推进，动画与结果展示期间不接受下一步动作，避免连跳。跟踪丢失会重置保持时间，不以离开摄像头当作剧情指令。

水上戏台右下角只保留“现在这样做”和“你会看到”两块信息。动作采用大号暖金文字，提示标签使用青绿色；角色缩略图、故事进度、预览框解释与重复说明均已移除。每次剧情换动作时提示卡会短暂亮起，以引导视线；系统开启“减少动态”时不会播放该提示动画。

MediaPipe Hands 已接入：使用本地 `@mediapipe/tasks-vision` 0.10.21 与官方 Hand Landmarker 模型，识别每只手 21 关键点；摄像头预览显示彩色关节点、连线和左右手标记。点击“开启摄像头 · 入戏”才请求权限。切换模式、离开戏台、关闭摄像头或页面进入后台会停止摄像头。画面在本地识别，不上传。捏合、松开、张掌、抬手、放低和挥动映射到当前剧情动作；右下方透明说明随情节更新，不必滚动找提示。成功触发与普通识别有不同的轻音反馈，可关闭声效。镜像输入与角色移动同向，可交换左右识别。主线程识别每秒最多约 15 次，带滞回、手离开重置和冷却；真人准确度仍需实际试演。

角色走位与动作落点会产生涟漪；风雨剧情增强水波，止雨或新一幕会恢复相应水势。基于现场“左手显示右手”的反馈，当前镜像输入标签统一经过 `anatomicalSide` 校正；骨架标签、角色分配与手势回调共用同一映射，手动“左右校准”可反向覆盖。左右手指用户自身，不按屏幕左右位置推断。真人手势的准确度、具体摄像头镜像设置仍需在实际设备试演调校。故事朗读使用浏览器中文语音；音乐是合成的五声音阶示意配乐。

视觉方案见 [备选预览](assets/concepts/备选预览.html)。九岛水道目录按岛屿坐标摆放九本悬浮秘籍，不再使用三乘三网格。白话文透明悬浮，竹卷半透明，控件统一为玻璃质感。五张戏台图通过单独标定开口嵌入剧情背景；角色从幕内走入前方宽水面，舞台占满视窗。新纯白九尾狐由 imagegen 编辑生成，保留旧图，提示词见人物资产目录内 `01_参考资料/图像校对_v004.json`；此次未调用 Blender。

首页点击“水波流动”启动水面折射、瀑布流光、云雾与灯笼闪烁，点击“暂停动态”停止。灯笼本体及岸边设有保护区，避免随水面大幅扭曲；减少动态偏好默认受到尊重。

### 本次素材与双手互动修订

- 人物、道具继续读取完整原图。运行时去背景改用更保守的颜色阈值、纹理边缘保护与小缺口修补，避免把浅色裙摆、金属盾面误当成背景；已有透明底图片保留原生 alpha，配角不再统一降低透明度。源文件不被覆盖。检查页 `scripts/check-sprites.html` 将 67 个人物/道具原图与实际显示并列，按故事筛选；水雾、光效与倒影仍有意保留透明。
- 提示卡按实际文字内容更新；仅进度、识别状态、播放状态改变时，不重建正文、不重播亮起动画。
- 双手段落仅用于《夸父逐日》《黄帝大战蚩尤》《夏后启取九歌》。夸父逐日：左手上下打拍驱动奔跑，右手抬升太阳；风雨交锋：左手挥动应龙水势，右手下压雨师降雨；乘龙登天：左手引启、右手引青龙同时抬升，赤龙配合。其余节点按剧情轮流驱动，提示始终写明左右手角色。
- 新增张掌上下轻点两次、转腕倾斜两种简单手势，分别用于奔跑/奏乐、舞蹈/月相。双手合力节点须两手都完成，可以相继完成（4.5 秒内），丢失跟踪会重置相应手的完成状态。其余六篇仍以单手为主，不改变精卫先女娃后精卫的顺序，也不修改白话正文。
- 自动化测试覆盖新增手势、三个双手故事、双手合力、超时与丢失重置，以及提示内容未变时不重建/不闪动。真实摄像头识别还需用户现场试演。

### 书册与动作定位

目录九册使用同一尺寸（相对原基础尺寸放大约 22%），取消远近缩放差异，保留岛屿位置与漂浮，左侧加卷轴式书脊，封面仍是书本。小窗口不再强制超宽目录。

`prop-rig.js` 保存以原图为坐标系的嘴部、持握和演奏定位。道具嵌入角色的动作层，因此拖动、键盘和 MediaPipe 走位都会一起移动；同幕动作重绘保留持物和飞行位置。精卫从现有石子素材取单颗石子，衔到嘴边，随鸟飞行，再从嘴边投出，落点生成水纹。持琴提高到乐师手部并以手指前景层覆盖琴面；弓箭、盾、长戈、木杖、战旗、护符、鼓也有各自的角色定位。捧日/捧月不再误拿水盆或其他首个道具。仍为 2.5D 图层动作，没有修改原始图像或白话正文。

运行 `node scripts/test-prop-rig.cjs` 验证资产归属和不同长宽比的定位。打开 `scripts/check-prop-rig.html` 可逐动作检查衔石、持琴、射箭等；“自动检查”验证连续动作、换步重绘、道具跟随与投射脱离，不启动摄像头。

## 后续替换位置

- `assets/hero-shanhai-3d-v1.png` 与 `water-surface.js`：新版首页群像和可暂停的水面折射动画；不是网页实时完整 3D 场景。
- `资料库/预览.html`：按故事、人物、道具、特效筛选的图片资料库；实际 `.blend` 下载链接单独标注。首页与精卫三幕的工程采用内嵌背景板及可编辑 3D 波浪水面，人物尚无独立骨骼。
- `assets/hero-shanhai-v2.png`：旧群像背景，右下角无头人物已移除；旧图 `hero-shanhai.png` 留作可恢复的原稿。
- `stories.js`：九则故事的顺序、整篇白话改编、动画线索、人物、能力与古文拼音。“刑天舞干戚”“鲧窃息壤”已从目录移除，先前删除的“大禹斩相柳”仍未收录。
- `asset-map.js`：资产编号到归档原图的索引，优先使用校对后的九尾狐、十二月版本。
- `scene-data.js`：九个故事的三幕、人物、道具、特效及操作指令逐项映射；含原典核查说明。
- `stage-renderer.js`：背景/人物/道具分层、运行时背景遮罩、倒影及动作。以后可替换为 Blender 渲染视频或 GLB 骨骼模型；当前不会改写原图。
- `experience.css`：新版简洁界面与响应式样式。旧 `styles.css` 保留，但已不再加载。
- `immersive.css`、`mythic.css`：全景阅读、水幕外景、岛屿书籍定位、透明竹卷、玻璃控件和前景舞台布局。
- `performance-data.js`：逐动作驱动角色、单/双手分配、自动情节和退场人物过滤。
- `theatre.js`：三种模式、手势与键盘输入、按剧情自动推进、出场与化鸟转场、水波和识别音效。`hand-input.js`：本地模型、摄像头生命周期、手势识别和骨架叠加。模型与来源见 `assets/mediapipe/`。
- `app.js` 暴露 `window.ShanhaiStage.setHandPosition(side, x, y)`、`triggerAbility(side, kind)` 和只读 `getSnapshot()`；`side` 为 `left` 或 `right`，`x/y` 为 0–1，左上为原点。位置接口仅在手势或按钮模式已启幕后生效，动作类型为 `pinch/release/raise/lower/sway/open`。

## 原典校对

古文选句对应《北山经》《海外北经》《海外南经》《大荒北经》《大荒南经》《大荒西经》《南山经》。每篇正文下有折叠的“改编说明”和原典链接。本次依用户决定 **只核查，不修改白话正文**。夸父的动机、启得天乐的具体曲调解释、常羲月相机制、青丘旅人幻境等不是原典直译，差异已逐项标注。水戏关键顺序按原典核查结果编排；神灵拟人化与水戏舞台本身为改编。拼音数量已验证，但正式教学版本仍应按选定底本复核异文、断句与多音字。

本版的背景图由内置图像生成工具制作，已保存到 `assets/`。本次修改对入口群像进行了局部编辑：

1. 首页与目录：山海经神灵与异兽聚于暮色水舞台，手绘水墨和矿物色，中央留文字空间，无字；右下角原有无头战士已从 `hero-shanhai-v2.png` 移除。
2. 动画与戏台：山水、湖泊、瀑布与松树构成的水墨景观，无字。
