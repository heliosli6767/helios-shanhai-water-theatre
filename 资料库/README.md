# 山海水戏数字资产资料库

所有新素材按单个资产保存。首页和九个故事已预建目录；空文件夹代表制作计划，不能当作已完成图片或模型。

```text
资料库/
├── 00_全局参考/
├── 01_首页_山海水戏/
└── 02_故事/
    ├── 01_精卫填海/
    ├── 02_夸父逐日/
    ├── 03_黄帝大战蚩尤/
    ├── 04_羿战凿齿/
    ├── 05_夏后启取九歌/
    ├── 06_羲和浴日/
    ├── 07_常羲浴月/
    ├── 08_青丘九尾狐/
    └── 09_鸾凤百兽之舞/
```

每个故事按背景、人物、道具、特效分类；每个数字资产独立一夹。例如：

```text
02_故事/01_精卫填海/
├── 01_背景/
│   ├── 第一幕_发鸠山与山林/
│   ├── 第二幕_明亮暴风东海/
│   └── 第三幕_海上礁石与渐生陆地/
├── 02_人物/
│   ├── 女娃/
│   ├── 精卫鸟/
│   └── 东海水灵/
├── 03_道具/
│   ├── 彩色石子/
│   └── 枯枝/
└── 04_特效/
    ├── 浪花/
    ├── 乌云/
    ├── 旋风/
    └── 水面涟漪/
```

每个资产文件夹内部统一为：

- `01_参考资料`：用户图片、网络来源链接、制作描述与生成提示词。
- `02_图片`：生成概念图、角色视图、贴图、渲染静帧。图片本身不代表有可编辑模型。
- `03_Blender`：实际 `.blend` 工程及对应生成脚本。没有工程时保持空目录。
- `04_导出动画与模型`：网页使用的 GLB、动画视频、序列帧等输出。

命名采用“资产名称_用途_v001.扩展名”，修改后保留旧版，新建 v002。动作使用中文可读名称，如“精卫鸟_衔石飞行_v001.glb”。

## 当前状态

125 个独立资产目录均已配有图片：123 项生成素材、2 项参考或旧版素材。其中九个故事共有 27 幕背景、37 项人物、30 项道具和 25 项故事特效，首页另有 1 张背景与 3 项效果设计。最新文件状态见 [制作状态](制作状态.json)，可打开 [图像预览库](http://localhost:4173/资料库/预览.html)。旧版与中断前已完成素材均保留。

首页与精卫三幕已有四个实际 `.blend` 工程：内嵌概念背景板 + 可编辑 3D 水面 + 5 秒波浪形态键。这是 2.5D 舞台原型，并非整张图的完整 3D 重建，图中人物无独立网格或骨骼。脚本位于 `scripts/build-water-scenes.py`。首页已接入可暂停的水面折射动画。

人物、道具 PNG 是立体风格概念图；特效 PNG 是效果静帧，均不等于已绑定模型、透明序列帧或流体模拟。

## 统一水戏规范与提示词

- 中国神话的立体场景结合越南水傀儡表演方式：每幕前景设置表演水池、倒影与波纹，中央留出演出空间。
- 草原、山路、陆地放在中远景或两岸；前景水池是舞台改编，不把故事改成洪灾。
- 参考《八仙》海报的体积、材质与电影灯光，以青绿、暖金、朱红保持系列感；暴风雨仍明亮可读。
- 背景、人物、手持道具和特效独立归档，便于后续骨骼动画与 MediaPipe 接入。
- 水戏前景修订使用 `*_水戏前景_v002.png`，预览库优先采用此版，旧版保留。
- 本批使用内置图像生成工具。每项提示词与来源保存在其 `01_参考资料/制作说明_v001.md` 或 `生成记录_v001.json`；修订提示词见 `水戏前景修订_v002.json`。

原始 `图片库/` 和网页正在引用的 `assets/` 均保留。资料库保存工作素材及版本；通过检查的网页发布素材再复制到 `assets/`，避免网页因素材整理而丢图。

目录编号使用当前九则故事的顺序，与旧的二十则故事编号不同；`资产目录.json` 中保留对应 `stories.js` 的 storyId。

完整列表见 [资产清单](资产清单.md)。目录可通过 `node scripts/prepare-asset-library.cjs` 重建，不覆盖已有文件。

## 精卫填海的已选视觉方向

- 首页：用户提供的“山海经首图”为构图依据，增强 3D 体积、中央水面和水傀儡剧场感。
- 发鸠山：东方海上仙山，青绿山体、暖金日光、层叠云雾。
- 东海：海上暴风雨，保持较明亮的曝光和可辨识的青蓝海水；不是暴风雪。
- 海礁：幻想海岛空间层次，前景少量石子和枯枝累积，新陆地仅开始形成。
- 女娃是炎帝之女、精卫前身，与女娲不同。东海水灵是这次互动改编的拟人化角色。
